# Agent Rules

- The project is currently in testing. Do not use recognition-result caching for image detection or naming tests; every scan must run the real current model and embedding pipeline.
- Item names must come from embedding retrieval against the category index. Do not add hardcoded Chinese name mappings or use detector labels as final item names.
- Each detected subject must run embedding-based naming, and subject naming should execute concurrently rather than serially.
- Storage structures are first-class detection targets: whole cabinets, storage boxes, drawers, cabinet doors, and compartments should be detected as boxes. The detector should support parent-child storage hierarchy so a large cabinet can contain individual drawers/cabinets, which can later contain detailed item photos and inventory locations such as living room -> large cabinet A -> drawer B.
- YOLOX subject-detection training must always run the fixed holdout evaluation set after training. Fixed evaluation images must never be copied into training data; use the training script's `--fixed-eval-dir` leak check for every training run. The frozen human-confirmed gold fixed-eval dataset is `/tmp/home-memory-yolox-fixed-eval-gold-v1/COCO`; candidate expanded eval sets must stay separate until human reviewed.
- When reviewing or relabeling the fixed evaluation set, always start a per-image local review page for the user, like `scripts/review-yolox-fixed-eval.py`, and let the user review images one by one. Save the user's per-image decisions and notes before generating the next fixed-eval version.
- Fixed-eval boxes must include the complete visible target subject, including edges, handles, lids, feet, and visible protruding parts, while keeping padding tight. Do not leave large blank margins just to be safe; do not crop off any visible part of the target.
- For future fixed-eval expansion, use a stronger open-vocabulary/grounding model as a boundary assistant before finalizing boxes. GroundingDINO-style targeted prompts are especially appropriate for precise coordinates of a known subject such as amplifier, turntable, cabinet door, drawer, rice cooker, filter module, or power adapter. Do not blindly accept large-model boxes; use them as candidates and keep review overlays/contact sheets.
- Keep evaluation tiers explicit: `gold-human-confirmed` for user-confirmed images, and separate candidate tiers such as OpenImages human boxes or strong product boxes until reviewed.
